              Capture a thought

              A note is plain text. These few things do something extra:

              • [[its first few words]], links to another note. Start typing [[ and a list of your notes appears; pick one to complete it. The link becomes a clickable chip on the saved note.
              • # A title on the first line becomes the note's title: the same thing the "Optional title" box above writes for you.
              • **bold**, *italic*, `code`, ~~struck~~, ==highlight== (or ==green|highlight==, also blue, pink, purple, orange; or select the words and use the ⋯ button), [text](url) and $x^2$ all render on the saved note.
              • tag: is for the filter box, not here, tags go in the tags field below, comma separated.

              Two things worth knowing, because they are easy to assume and both untrue:

              • There is no / command menu in this box. Pressing / anywhere you are not typing jumps to the search box; inside a document, Ctrl+/ comments the line. Neither is a note-composer command.
              • Headings beyond the first line, lists, tables, fenced code and > [!tip] callouts are stored faithfully but are not rendered on a note card, a note list rendered that way gets very tall very fast. They do render in the document editor.

          These follow the conventions every app shares, so they aren't
          rebindable: being unable to press Escape in the dialog you rebound it
          in is not a state worth allowing.
        
                                                                                
      
                                                                                
      
                                                                                  
        
                                                                                • EscClose any dialog, menu, or overlay
                                                                                  • 
        
                                                                                • ← →Move between tabs (when a tab is focused)
                                                                                  • 
        
                                                                                • EnterSend a chat message, or run the selected command
                                                                                  • 
        
                                                                                • TabMove focus; cycles inside an open dialog
                                                                                  • 
        
                                                                                • m then d/n/c/g/l/t/rJump to Dashboard / Notes / Chat / Graph / Library / Timeline / Reminders
                                                                                  • 
        
                                                                                • m then s/q/vOpen settings / a quick sketch / meeting notes

                                                                                 Meeting notes
                                                                                
          
        
                                                                                
        
      
                                                                                
      
                                                                                Record anything longer than a quick note, transcribed on this machine.
                                                                                
      
                                                                                
        
                                                                                
          A meeting, a lecture, or anything the mic button in the composer is
          too short for. Whisper does the transcription, the same engine behind
          that button, and nothing leaves this machine.
        
                                                                                
        
                                                                                
          The transcript comes back for you to read and trim before anything is
          saved. An hour of talking is a document rather than a note, which is
          what the second save button is for.
