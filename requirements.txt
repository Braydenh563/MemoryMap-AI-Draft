# Direct dependencies, with upper bounds.
#
# Every line caps the next major version. Lower bounds alone ("fastapi>=0.139")
# mean a breaking upstream release lands silently on the next clean install and
# the app stops working for reasons that have nothing to do with your changes —
# sentence-transformers and torch both have a history of exactly that.
#
# These are ranges, not exact pins, because torch resolves differently per
# platform and a single pinned file can't be right everywhere. For a fully
# reproducible install, generate a lockfile on your own machine:
#
#     make lock        # writes requirements.lock.txt with exact versions
#     make install-locked
#
# Regenerate it whenever you change this file.

# zoneinfo (stdlib) has no bundled tz database of its own — on Linux/macOS it
# reads the system's /usr/share/zoneinfo, which is usually present, but
# Windows ships no IANA tz data at all, so `ZoneInfo("Australia/Brisbane")`
# (or any non-UTC zone) raises ZoneInfoNotFoundError there every time,
# silently falling back to the server's own zone (core/config.py's
# `user_now`). This is that fallback's actual cause on Windows, not a bad
# zone name. tzdata is pure data, ~500KB, and safe to install unconditionally
# on every platform (Python prefers the system database when one exists).
tzdata>=2026.3

# torch: on Windows, force the CPU-only build. The default Windows torch wheel
# now ships Intel's torch_xpu.dll, which fails to load on many machines with
# "WinError 127: The specified procedure could not be found" — that crashes the
# embedding backend and silently drops semantic search back to keywords. This
# app only ever runs embeddings on the CPU, so the CPU build is all it needs
# (and it's ~10x smaller to download). Other operating systems are unaffected:
# the marker skips this line and torch installs normally via sentence-transformers.
# The extra index is where pip finds the +cpu wheels. See the README's
# Troubleshooting section if you already installed the broken wheel.

# Encryption at rest for notes marked private (AES-GCM). scrypt comes from
# the stdlib; this is only needed for the cipher itself.
#
# Floor is 49.0 because two advisories against <= 48.0.0 are fixed there: an
# exponential blowup in certificate path building on chains with duplicated
# self-signed intermediates (a DoS amplification), and a verifier that accepted
# a wildcard SAN escaping an intermediate's permittedSubtrees. Neither is
# reachable from this app — nothing here builds or verifies an X.509 chain; it
# uses the AES-GCM cipher and nothing else — but the floor costs nothing and
# Dependabot was blocked by our own `<47.0` ceiling rather than by any real
# incompatibility. Verified against 50.0.0, which the suite runs on.
cryptography>=50.0.1,<51.0
